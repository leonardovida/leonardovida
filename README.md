# Hi, I'm Leonardo

I'm a technical Account Executive at [MotherDuck](https://motherduck.com) - before I worked Senior Customer Engineer / FDE. I still spend a good chunk of my time on the technical side doing discovery & architecture, running pilots and following customer deployments (and building internal tools)

Most of my work falls into two areas:
- **Production agent systems**: I build workflows to repro and fix issues, improve customer support, and run automated analytics across our customer base. Currently I'm learning more about evals and how to enable our customers to run autonomous agentic improvement loops with them
- **The DuckDB ecosystem**: I maintain connectors, extensions and tooling that I think fill gaps around DuckDB

I use AI heavily in both. I'm still trying to setup a fast local agent environment, but you'll find me using frontier models most of the time

## Current projects

Main project:
- [duckdb-ai](https://github.com/leonardovida/duckdb-ai) - SQL-native ai functions for DuckDB - soon leveraging Quack to leverage external routing services

Others:
- [drizzle-duckdb](https://github.com/leonardovida/drizzle-duckdb) - a Drizzle ORM adapter for DuckDB
- [duckdb-sqlalchemy](https://github.com/leonardovida/duckdb-sqlalchemy) - a production-focused SQLAlchemy dialect for DuckDB and MotherDuck
- [duckdb-finance](https://github.com/leonardovida/duckdb-finance) - SQL-native financial functions for DuckDB
- [MotherDuck Agent Skills](https://github.com/motherduckdb/agent-skills) - an open-source catalog that teaches coding agents how to explore schemas, write DuckDB SQL, use the MotherDuck API, and build data applications
